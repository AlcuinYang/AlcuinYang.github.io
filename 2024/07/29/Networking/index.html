计算机网络网络层笔记

网络层

网络层有两部分功能：

  • forwarding(转发)：从输入路由移动packet到合适的输出路由——data plane
  • routing: 确定数据包从源到目的地所采取的路线 —- control plane

    控制平面

    常见的两种方法来构造控制面：
  • pre-router control：在每个router中都有的独立的算法，每个路由器中的各个路由算法组件在控制平面中相互作用
  • logically centralized control(Software Defined Networking-SDN)：远程控制器计算并在路由器中安装转发表

    路由协议

    用来确定“好的”路由路线：
  • path：
  • good：最少消耗，最快速度，最不拥挤

分类

  • 全局：所有router都有完整的网络拓扑
  • 去中心化：
  • 动态：周期性更新routes
  • 静态：更新routes比较慢

    常见算法

    Dijkstra 算法

    Bellman-Ford 算法

OSPF(Open-Shortest-Path-First)

因为有太多的des router所以没法全部保存在table中，通过把routers 聚合在一些region的方法叫做autonomous system
AS 又分为两种

  • intra-AS： 在同一个网络内路由
    • 同一个AS的routers 有相同的intra-domain protocal
    • 不同AS的routers可以有不同的intra-domain protocal
    • gateway router：在AS的边缘，有通往其他AS的router的link
  • inter-AS：在AS之间路由

什么是OSPF

  • open: publicly available
  • link-state:
    • 每个routers都将link-state通过IP将其通报
    • 多种cost matrix：带宽，时延
    • 每个路由器都有全部拓扑，使用Dijkstra计算转发表
  • security:

分层OSPF

两层分层： 本地网和骨干网

  • link-state 在本地网和骨干网中传播
  • 每个节点都有详细的area topology，只知道去其他des的方向

BGP(Border Gateway Protocal)

BGP是事实上的inter-domain的路由协议，是将网络连在一起的胶水。它保证了子网可以广播自己的存在、可以到达的des，和广播到剩下的网络

BGP的作用

可以让AS：

  • 从相邻AS（eBGP）获取目标网络可达性信息
  • 确定去其他网络的路线
  • 将可达性信息传播到所有AS-internal routers（iBGP）
  • （向相邻网络）通告目的地可达性信息

    BGP 基础

  • BGP session: 两个BGP router通过半永久的TCP链接交换msg
  • msg的类型包括
    • OPEN
    • UPDATE
    • KEEPALIVE
    • NOTIFICATION
  • BGP 是policy-based routing，网关通过导入的policy来决定接受或者拒绝某些path
  • 当BGP router接收到path advertisement 之后会传播给所有在本AS的router

    BGP的实现策略

    在正常的生产生活中，企业通常会接入多个ISP，但每个ISP只想在自己与自己的顾客之间route traffic。对于下面这张图：
  • A 宣传路径 Aw 到B和C
  • B 选择不把路径BAw宣传给C，于是C不能获得CBAw这个路径
    • 因为C和A都不是他的顾客，没有回报
  • C 会通过CAw 这条路径来到达w

BGP路径选择

router 会基于以下因素来进行路径选择：

  • 最短的AS_PATH：经过的AS越少，通常为更优
  • local preference属性：在本地路径自定义的优先级value
  • 最近的NEXT-HOP router：hot potato routing，可以理解为尽可能快的把消息转发出去

Softwre Defined Networking (SDN)

在过去，每个路由器中都有单独的路由算法组件来与计算机转发表的控制层面交互。

  • 对于SDN，通过一个远程控制器来给路由器计算和安装转发表。通过这样就可以将控制欲转发平面分离，让数据转发平面的设备变得相对简单，只专注于数据开发。
  • 通过一个中心化的控制器，可以带来很多方便
    • 更容易的网络管理：网络的拓扑结构、设备状态、流量信息、
    • 可编程性和更灵活
